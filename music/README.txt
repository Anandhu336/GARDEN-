Converted to AAC (.m4a, 96 kbps) so they are small and play on iPhones as well as Android and computers.

TO ADD YOUR OWN SONG
1. Put an .m4a or .mp3 file in this folder (about 2-4 MB is ideal; use music you are allowed to publish).
2. Open index.html, find the TRACKS list near the top of the script, and add a line:
     { id: 'mysong', name: 'My song', file: 'music/my-song.m4a' },
   The id must be short with no spaces. It is stored in the shared link, so never change it later.
3. Upload index.html and the music folder to GitHub again.
